# 自定义每日内容与打卡时间

从侧栏打开“设置与运行”，找到“日常内容与打卡时间”。也可展开“每日一学”“每日反思”或“睡眠打卡”文件夹，点击其中的设置入口。手机与电脑保存到同一个账号空间。

## 每日一学

点击“内容要求”，分别填写经典古籍、中国史与党史、现代概念的近期主题。输入框会提供当前已经取得正文的材料标题作为建议，也可以填写自己的主题关键词；多个关键词用顿号或逗号分隔，表示可选方向。留空的分类继续自动扩充和选材。

“授课要求”决定怎样讲授，例如“先解释原文，再提供一个完整示例，最后给一道可选的思考题”。主题参与实际选材，授课要求参与备课；已有的长期交流偏好仍会使用。

保存后显示版本、变更内容和生效范围。新主题用于尚未发布且未展开讨论的预备课程及之后的新课程。已发布或已讨论的课程保留原选材及出处，授课要求可用于后续追问。如果所填主题暂时没有匹配的已取得原文，回执列出相应分类和主题，课程保持待补材料状态。可以选择已有材料，或者清空相应主题恢复自动选材。

也可以在起居对话中分别发送以下指令，示例主题是否可用取决于该实例已经取得的材料：

```text
每日一学经典主题改为 知行合一
```

```text
每日一学历史主题改为 毛泽东诗词
```

```text
每日一学现代概念主题改为 劳动价值论
```

```text
每日一学教学要求改为 先解释原文，再用一个具体例子说明，最后给一道可选思考题
```

```text
每日一学恢复自动选材
```

“恢复自动选材”清空三个分类的近期主题，保留教学要求。

## 每日反思

点击“反思方面”，可修改名称、回顾重点，添加或移除方面，共支持 1—12 个方面。需要时展开“匹配关键词”，填写聊天中可能提到的词，以顿号、逗号或换行分隔；留空时使用方面名称。

例如把方面设为“科研进展、身体状态、家庭生活”，并给“科研进展”填写“回顾具体进展、遇到的约束和下一步”。之后新建的反思，包括新补填的历史日期，使用这组方面。已开始的反思保留创建时的方面，在侧栏“当前记录”可查看，既有对话和成长记录不改写。

若只需替换方面列表，可以直接发送：

```text
每日反思方面改为 科研进展、身体状态、家庭生活
```

单次对话仍可自由深入。保存方面不要求每天按固定问卷逐项作答。

## 三类打卡时间

在对应活动旁点击“打卡时间”，选择 24 小时制时间。全部时间按北京时间（Asia/Shanghai）解释。每日一学提前备课，到设定时间发布；该时间不是开始准备材料的时间。

仅修改时间会保留原星期安排和暂停日期。默认三类活动每天触发，只有明确修改星期或暂停日期才改变频率。历史补填和手动聊天仍可使用。

也可以逐条发送：

```text
每日一学时间改为 20:30
```

```text
每日反思时间改为 22:00
```

```text
睡眠打卡时间改为 08:00
```

活动按所选时间安排；外部通知仍遵循北京时间23:00—08:00免打扰，期间可直接打开网页查看。

每次保存返回实际下一次时间；当天已过的时刻不会倒补一次新提醒。有限期暂停包含所选日期，次日恢复原安排。

## 核对已保存设置

发送：

```text
查看当前打卡设置
```

会列出学习主题与教学要求、反思方面，以及三类打卡时间和下一次安排。聊天中的“设置处理回执”来自程序实际保存结果。

网页表单保存失败会保留当前输入；原样重试沿用同一提交编号。若提示另一窗口已更新，先保留自己的修改文本，关闭表单、刷新页面，再基于最新版本修改。
