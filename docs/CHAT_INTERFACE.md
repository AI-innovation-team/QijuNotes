# 聊天界面与断线恢复

默认进入聊天或上次活动，通知深链接优先打开指定活动。界面采用起居品牌、图标导航、会话侧栏和居中消息区。

- 中间保留消息、当前问题及底部输入框。发送用上箭头图标；Enter换行，Ctrl/Command+Enter发送。
- 最左侧图标打开今日、历史补填、聊天、起居注·个人史、日程、对话原文、学习收藏、委托、成长、资料、设置。图标提供悬停说明和辅助名称。
- 每日一学、睡眠打卡、每日反思分别是项目文件夹，展开后按业务日期倒序列出全部已有日期；各有“打开今天”，历史补填仍可用。
- “最近对话”只显示最近60项 `CHAT` 日常聊天，三个例程不会出现在这里。
- 当前活动的继续、跳过、结束、稍后提醒、关联委托、摘要、更正、附件与原话管理保留在侧栏。删除仍要求查看影响范围并确认，不因改图标改变权限。
- 手机上点左上侧栏图标打开抽屉，点遮罩/关闭图标或Escape收起；收起后的控件不进入键盘焦点。
- 任务、日程、成长和导入的完整页面仍从侧栏进入，没有删减原功能。

起居的身份是个人史秉笔史官，使用[项目头像](../web/qiju-avatar.png)。设置可自定义记载称谓，未设置时默认“用户”。个人史由本人来源自动形成，原文独立保留；事实、计划与判断分别表达，可事后更正或删除。详见 [个人史](CHRONICLE.md)、[日程](CALENDAR.md) 和 [材料准备](MATERIAL_PREPARATION.md)。

界面默认蓝白配色，侧栏月亮图标切到夜间深色，太阳图标切回。选择只保存在当前浏览器；存储不可用时会提示无法记住选择。正文与输入框采用较大字号和行距，空输入框起步一行，随文字增加高度，到上限后内部滚动。清空或对应发送回执成功后缩回一行。

Markdown 支持标题、段落、嵌套列表、引用、表格、代码及安全 HTTP/HTTPS 链接。宽表与长代码局部横向滚动；原 HTML 和脚本按文字呈现，远程图片不自动加载。渲染不改数据库原话、导出或草稿。

连接状态以实际请求为准。请求失败不会自动清空现有对话或输入；返回前台、恢复网络或点击“重新连接”会重建事件连接并读取已保存状态，重试逐步退避，最长间隔 30 秒。

只有持久回执才能清除已提交文字。回执不确定时，点击原提交的重试入口，服务端按稳定编号去重；不自动重新发送。等待期间继续编辑的新文字不会被上一条回执清除。草稿仅在同一浏览器保存，跨设备同步和清除站点数据后的恢复不在保证范围内。

网页登录条件见 [账号说明](ACCOUNTS.md)。手机系统停止 VPN 后网页无法自行启动它；连接设置见 [HarmonyOS](HARMONYOS.md)。实际手机、输入法、长时后台和锁屏通知应分别验证，不能以缩小浏览器视口代替。

“问题反馈”可保存功能需求和实际处理回执，但不会自行修改界面代码。当前没有完整隐藏推理展示；后续增加状态动画或思路摘要仍需实现、验证和发布。
