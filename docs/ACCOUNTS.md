# 账号密码与保持登录

起居使用单用户账号密码。账号与通知订阅账号相互独立；重设网页登录账号不会删除已有对话和任务。

## 第一次设置

在部署服务的 Linux 电脑浏览器打开 [本机入口](http://127.0.0.1:18780/)，填写账号、密码和确认密码，点击“创建账号并进入”。账号为 2–64 个字符；密码为 10–256 个字符，可使用密码管理器。

首次设置仅接受真实回环连接和严格同源请求。手机看到“请先在电脑创建账号”时，先在主机完成一次设置。系统不提供默认密码；账号建立后，旧长密钥和旧临时登录会话失效。

## 日常登录

其他设备使用部署者配置的私网入口和同一账号。勾选“在此设备保持登录30天”后，有效会话可以跨浏览器关闭和项目服务正常重启保持；未勾选时使用浏览器会话 Cookie，服务端最多保留 12 小时。清除站点数据、退出、改密或本机重设后需重新登录。

设置中可更改密码，更新后撤销其他设备会话。密码不进入日志、URL、网页本地存储或导出；连续错误尝试受到限流。

## 本机恢复

能登录部署主机的操作者，在项目根目录的交互终端运行：

```bash
python3 scripts/account.py reset
```

按提示设置账号与新密码，输入密码时不回显。不要将密码写入命令参数或聊天。`status` 只报告账号是否已配置，`setup` 用于尚未初始化的实例；自定义数据目录使用 `--data /absolute/path/to/data`。

数据根的 `account-auth.json` 保存带随机盐的 scrypt 摘要和会话哈希，权限为 0600。账号文件、会话和临时认证文件不进入导出或备份；恢复到另一实例后重新设置账号。异常权限、符号链接或损坏文件会使认证失败，不能退回旧密钥绕过。

账号登录不代替设备到主机的网络连接。私网接入见 [安卓说明](ANDROID.md)，后台连接问题见 [HarmonyOS 说明](HARMONYOS.md)。
