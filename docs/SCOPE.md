# 当前功能与边界

起居是单用户、自己托管的日常交流与个人史应用。公开仓库提供源码、通用文档和隔离测试，不携带部署实例的私人数据、验收记录或运行历史。测试通过与真实模型、手机、恢复目标和长期运行是不同验证范围。

| 功能 | 当前实现 | 边界 |
| --- | --- | --- |
| 日常活动 | 每日一学、每日反思、睡眠打卡；按日期归档并持续对话 | 默认每天；只有明确用户操作改变频率或暂停 |
| 历史补填 | 单日、多日、较早日期，原业务日与实际提交时间分开 | 不把缺记录推定为没行动，不补发历史首次通知 |
| 长期要求 | 保存、查看、替换、停用全局与例程偏好，版本化回执 | 内容偏好不更改程序、权限、模型凭据或提醒频率 |
| 学习主题 | 主题要求可保存并用于生成提示 | 尚未贯通主题驱动检索、选材与课程规划 |
| 问题反馈 | 保存原话、处理状态和实际处理结果 | 不会自主改代码、测试或部署；开发者处理后更新回执 |
| 夜间研读 | 经启用后在限定窗口逐段读已登记来源，保留笔记与出处 | 默认未启用；视频目录或标题不算读过，未取得正文的条目等待材料 |
| 个人史 | 基于本人来源自动形成第三人称记载，可自定称谓并更正 | 不把助手建议、假设、计划或科学判断升级为已验证事实 |
| 材料 | Kimi、ChatGPT、Codex 文件预览、去重、来源及版本保留 | 不自动登录平台或同步全部私人历史 |
| 画像与成长 | 作用域偏好、三条成长主线、来源和修订关系 | 历史导入不自动成为当前画像、已完成成果或用户评价 |
| 委托 | 一次性或周期任务、需求修订、版本成果、用户验收 | 可用工具和授权范围受限，模型自评不能代替用户验收 |
| 日程 | 月、周、日视图，24 小时时间轴，选择性提醒 | 目前是单次日程；到点或收到通知不表示完成 |
| 手机界面 | 响应式聊天、Markdown、草稿、蓝白与夜间主题 | 草稿在本浏览器；后台网络依赖系统，回执不等于设备送达 |
| 备份与删除 | 加密快照、独立恢复账本、隔离恢复、来源删除传播 | 账号与凭据不迁移；异机恢复必须在实际目标单独验证 |

## 运行约束

应用由一个业务调度入口和一个 DSH Web 写入宿主维护。SQLite 事务和持久回执决定状态，模型说“已完成”不能替代实际提交、发布、通知或验收。未知外部动作结果不自动重放。

模型网关支持受控的兼容 Chat Completions 服务，独立凭据文件和本地后台预算。供应商余额、限流、网络和内容质量仍需部署者核对。当前界面不展示模型的完整隐藏推理过程；聊天中提出动画或思考展示需求也不会立即增加界面代码。
