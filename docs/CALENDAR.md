# 日程与提醒

从侧栏的日历图标打开日程。可按月、周或日列表查看；周视图提供00:00—24:00时间轴，手机可在网格内横向滚动；选择日期后新建安排，填写名称、起止时间、全天选项、地点或会议入口、备注。时间明确使用上海时区。跨日安排会出现在它覆盖的日期中。

提醒默认关闭；选定提前分钟数后才接入已有私网手机通知。通知只显示“日程提醒”和打开链接，日程标题、地点与备注不出现在锁屏正文。新日程不改每日一学、睡眠打卡、每日反思的固定频率。当前提供单次日程，周期性例程继续使用原有每日调度。

已保存的安排仍是“计划”，到点或收到通知不会自动写成完成。本人点击完成并确认后，个人史只记“确认完成日程”，按实际确认日期留痕；取消也需明确操作并保留原计划。编辑需匹配版本，旧页面不能覆盖新修改。完成或取消后的记录不直接改写为另一件事，必要时新建安排。

网络丢回执后，同一个新建表单沿用原提交编号重试，不会新增重复日程。提醒发送中的安排暂不能编辑，避免“已改时间但旧提醒同时发出”的竞态；状态不明时不自动重发。主机恢复上线后，已经结束的安排不补发；手机通道没有配置时只显示页面提醒状态。

手机通知依赖实际网络、Tailscale与系统后台管理。应分别验证日程深链接和锁屏到达；活动通知通过不自动证明日程通知通过。

日程、取消/完成动作、提交编号和通知回执进入加密备份及独立恢复账本。旧快照合并较新账本时保留取消/完成与已发生的通知效果；未确定提醒转为恢复待核，不能自动重放。恢复隔离解除后，需要重新核对未来提醒并显式编辑保存。账号凭据仍不进入备份。

新增日程表属于schema1的附加结构，不改既有活动或会话字段。旧版程序不认识日程功能，回退程序前须同时评估新安排和提醒，不能把界面回退当作日程仍会执行的保证。
