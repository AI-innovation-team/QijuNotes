# 起居注：由起居自然形成的个人史

起居担任个人史秉笔史官，依据可追溯的本人原话自动记载重要经历、行动、决定、阅读、进展与生活变化。个人史形成不需要本人逐条批准。本人可以随时更正、补充或删除；原始对话独立保存在“对话原文”，不是逐条等量搬入个人史。

## 自动形成与编修

来源充分的重要用户自述会自然进入“已记载”。学习自动推送、助手建议、模型参考稿、打开页面和收藏动作本身不构成本人经历；明确阅读原话才可以记为已阅，阅读也不等于掌握。技术测试、假设案例和他人经历不冒认为本人事迹。

起居先以来源归因的简要叙述记录，再通过现有后台预算网关逐步提炼文字。后台每30秒检查新来源，每轮最多新排10份编修，持久队列去重；一般失败有三次上限，额度/并发429暂时不足时保留同一任务，15分钟后再试。模型不可用或来源过长时，原话与来源归因记载仍保留，不为等待编修要求本人批准。规则提取可能遗漏未明确表达的重要事件；可直接说“记入起居注：……”或事后补充，不要求把每句话都转成史事。

模型编修只使用有效用户来源。平台输出的assistant参考稿可以保留为资料，不能冒充本人原话或独立事实。计划必须记为计划，个人感受、判断和实验观察保留自述归因；不能自动升级为独立核验的事实、成就、因果或科学结论。前后更正、否定及未完成语境必须一起保留，不用重要性关键词筛掉短更正。

“待整理”只表示信息不足或还需组织内容，不是等待本人批准。“已记载”表示起居已依据来源形成记录，不表示所述科学结论已被验证。系统自动稿以`qiju_agent`标记，`confirmed=False`，不会伪造本人确认；这些内部标记不影响其正常记载。原有本人更正优先，历史上已经确认的稿件和反馈仍保留。

## 日期、称谓与出处

设置中的记载称谓默认“用户”，可自定；记载采用第三人称列传式叙述，不发明姓名、头衔或称号，必要的原话引用保持原样。自动编修使用当时称谓；已由本人写定的更正正文不被静默重写。

本地条目按活动原业务日期归档，同时保留实际记载时间。历史来源保留原时间，未知就显示未知，不能以导入日期或模型整理日期冒充事件发生日。导入按主来源定位编修，相关上下文用于解释后续更正，不把整个会话重写到每个主来源的原日期。日程只有本人实际确认完成才记录该确认行为，排期到点不自动证明活动已经发生。

每份自动稿绑定模型看到的全部用户来源，并保留实际引用。重要内容与修订都能追到原始消息/导入文件；原始全文另存。跨平台同一事件保留不同出处，精确重复可去重，冲突保留来源，不擅自裁决。

## 更正、删除与恢复

个人史页面可直接更正正文或暂不记载；暂不记载只改变史事展示，不删除原话。更正采用版本检查，旧页面不能覆盖新输入。本人更正或排除优先于自动稿；模型运行期间出现来源变化、更正或删除时，旧生成结果不能提交。

自动稿使用现有版本化`records_profile`，限定`chronicle`作用域，不自动进入全局画像或普通模型上下文。来源删除/批次撤销会清理相关派生正文。来源变化使旧自动稿过期，先退回当前来源叙述，再等待新编修；删除后的新独立来源使用新代次，避免旧删除账本误删新稿或复活旧稿。恢复必须合并较新修订、删除和动作账本，先隔离核对，不自动重放旧通知或任务。

## 接口边界

`Chronicle`本身不调用网络；Worker调用已有预算网关编修，再以来源指纹和版本提交。接口包括`settings/save_settings`、`entries`、`revise_entry`、兼容的`confirm_import_entry`（当前用于可选更正）、`automatic_targets`、`automatic_snapshot`、`commit_automatic`及删除事务中的`prune_chronicle_corrections`。自动稿提交不会制造用户聊天消息、本人评价或整个项目验收。

个人史自然形成与任务成果验收是不同业务。委托成果版本及整个项目是否被接受，仍由本人明确决定。


批量文件的`source`记录作为独立来源说明传给史官：它可说明未知时间、截断和导出范围，不能充当本人经历或可执行指令。自动稿依赖所有实际提供的原话和来源说明，任一依赖删除或变化都会使旧结果失效。参考材料综述保存在`reference:personal-history`并展示于资料页，可更正或收起；不会静默变成当前全局画像。

编修任务优先级低于例程与主动交互，同时最多一个史官任务执行。内部`historian-model`使用已配置供应商并计入后台用量。在启用本地限额时，原子检查需留下30,000 token每日余量；不足时15分钟后重试，不自行增加限额或调整日程，月限额同时约束。完整请求即使在空预算周期也不能容纳时明确失败并保留原话，不无限重排或截断来源；需按完整事件分组或明确预算变更后处理。
