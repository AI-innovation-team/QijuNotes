# HarmonyOS 后台连接排查

起居网页和私服通知依赖手机到主机的连接。使用 Tailscale 时，VPN 在后台停止会同时影响网页与 ntfy；网页代码不能自行重启被系统关闭的 VPN。

## 先区分服务故障与手机断线

在部署主机执行 `bash scripts/control.sh status`，检查应用、原生宿主和通知服务；在主机打开本机网页。再检查手机 Tailscale 是否连接、浏览器是否能打开私网入口、ntfy 主题是否能刷新。主机自身能访问私网地址不代表手机当前可达。

## 手机后台设置

系统菜单可能随机型和版本变化，可按实际名称检查：

1. 在应用启动管理中，将 Tailscale 和 ntfy 设为手动管理，允许自启动、关联启动和后台活动；允许通知。
2. 在电池设置中启用“休眠时始终保持网络连接”（若提供）。
3. 在最近任务界面锁定 Tailscale 与 ntfy 卡片，避免一键清理停止它们。
4. 重新打开 Tailscale，确认连接；打开 ntfy，确认主题可读，然后回主屏再锁屏验证。

这些设置减少系统关闭后台进程的机会，不构成送达保证。不要把测试时刷新后才看到缓存消息记成实时锁屏送达。

## 分别记录结果

将短时返回、长时锁屏、网络切换、网页登录保持和通知到达分别记录。账号的 30 天保持登录解决认证有效期；网络断开仍须恢复连接。发生未确认提交时使用原提交的重试入口，不复制发送多条。

公开源码不携带某个用户设备的观测记录。每个部署需要保留自己的实际结果，参见 [账号](ACCOUNTS.md) 和 [安卓通知](ANDROID.md)。
